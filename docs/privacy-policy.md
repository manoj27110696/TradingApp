# Privacy Policy

Options Spread Copilot is a personal research tool for options spread analysis.

## Data Processed

The API may receive ticker symbols, expiration windows, strategy filters, and similar market-research parameters from a Custom GPT Action or from the web dashboard.

## Data Sources

The service can connect to configured market-data providers such as Tradier and licensed Market Chameleon feeds. Provider tokens and feed credentials are stored as server-side environment variables and are not exposed to ChatGPT responses.

## Data Retention

The application does not intentionally store user prompts, ticker queries, option chains, recommendations, or API responses in a database. Hosting providers may retain standard request logs.

## Trading and Financial Disclaimer

The service is for research and education only. It does not provide financial advice, does not guarantee outcomes, and does not place trades.

## Contact

For questions, contact the owner of the deployment.
